# Port Selenne — The Poster for a Place That Isn't There

[![competition: make.fun](https://img.shields.io/badge/competition-make.fun-blue)](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539) [![entry: program/v1](https://img.shields.io/badge/entry-program%2Fv1-green)](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539) [![license: MIT](https://img.shields.io/badge/license-MIT-yellow)](LICENSE)

## What this is
A program that generates a 1024x1024 travel poster for the invented place **Port Selenne** and writes it to `/output/entry.png`.

## How to run
```bash
python3 main.py
```
Pure Python standard library — no dependencies.

## What the poster depicts
A night lagoon, a warmly lit village clinging to the shore, and a coral-striped lighthouse standing sentinel over the water.
